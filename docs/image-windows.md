# 图像分窗与点时间诊断

本开发版通过 `FAST_LIVO_STRICT_WINDOWS=1` 启用严格分窗。默认沿用 B1 分配。开关在进程启动时读取，适用于 LiDAR、IMU、图像联合工作的 LIVO 模式。

## 分窗规则

每个有效回波的采集时刻取扫描头时刻加预处理后的 `curvature / 1000` 秒。严格模式要求偏移有限且非负，各扫描进入队列前按偏移排序。两种 LiDAR 回调遇到早于最新扫描头的消息均拒绝该条消息，并保留原有点云和时间戳队列。传感器重启、时钟回绕或向前一段数据重新定位时应开启新会话。

对于半开区间 `[上次 LIO 时刻, 本次图像时刻)`，严格模式逐个扫描消费本窗前缀。等于窗末的点保留到下一窗，保留部分一直使用原扫描头和原始偏移。若扫描之间有交叠，归一到窗首后按采集时刻排序，再送入逆序去畸变。阈值不参与窗末归属判定。按传感器绝对双精度时钟判断为等边界后，换算到局部毫秒可能出现小于 1 微秒的负舍入量，此时将窗首偏移置零。

在线处理等到已收到的扫描起点达到窗末，未来的单调扫描起点和非负点偏移才能保证没有先前窗口的回波仍在传输中。单靠已有扫描的尾点越过窗末无法排除下一扫描与它重叠。等待时间取决于扫描间隔和到达延迟。离线 reader 确认真实 EOF 后，使用所有剩余扫描的最大有效点时刻作为覆盖上限。两条路径均要求 IMU 已覆盖图像时刻。最后一幅图像之后的回波留在队列中，没有虚构新窗口。

## 回归

`image_window_regression` 构造三个切点、重叠扫描、同时间戳不同点、等边界和空窗，按点 ID 验证唯一归属。在已知 1 m/s 匀速轨迹上，它调用生产 `ImuProcess::Process2` 验证每个点变换到窗末的位置。水位用例按真实到达顺序先给越过窗末的长扫描，再给一条此前尚不可知的重叠扫描，最后给确认水位的扫描。EOF 用例验证最远有效末时刻。合同回归 `contract_regression` 另从标准点云和 Livox 两种回调投递倒序帧并检查原队列的头、数量和点云对象。

## 诊断复算

单独设置 `FAST_LIVO_DIAGNOSTICS_DIR` 可指定输出目录。离线模式同时设置 `FAST_LIVO2_OFFLINE_BAG` 与 `FAST_LIVO_KEYFRAMES` 时，默认写入该关键帧目录。在线只开启关键帧导出时不计算逐窗口诊断。

```sh
python3 tools/summarize_frontend_timing.py B1/keyframes --out b1_timing.json
python3 tools/summarize_frontend_timing.py STRICT/keyframes --compare B1/keyframes --out strict_timing.json
python3 tools/inspect_bag_clocks.py /path/to/raw_bag /path/to/run/sensors/camera > bag_clocks.json
```

汇总保留实际接纳窗口、超过窗末 1 微秒的点数和时间差、边界带、去畸变消费、IMU 初始化样本，以及最终 LIO 迭代的点到面约束。实际回放按窗口核对数量守恒，合成回归按唯一 ID 核对不重不漏。地面和顶面候选由当前重力方向、平面法向与相对雷达高度划分；水平面倾角上限为 20°，高差须大于 0.20 m。墙面候选的法向与重力近似垂直，容差为 20°。各类比例按匹配点计数，不能直接换算为实际面积或位姿精度。

## 量测权重与六维几何信息

启用诊断后，算法按采集时钟每隔至少 1 秒抽取一次 LIO 更新。先在本次计算 Jacobian 的位置记录每个匹配实际使用的平面方差、点协方差在法向上的投影和逆方差权重，再保留本次最终迭代的数据。固定方差为 0.001 m²。各类的平均权重由实际逆方差逐点求和后除以数量得到。地面、顶面和墙面的竖直平移信息贡献分别累加 `R_inv × (n·up)²`。

六维矩阵直接复用本次更新已建好的 `Hsubᵀ R_inv Hsub`，没有状态先验。取本次所有匹配点到 IMU 原点的实际杠杆臂均方根为 `L`，将增量统一成世界坐标的 `[L·δθ, δx]`。若 `R` 是当前线性化 IMU 姿态，则从该坐标到原生混合坐标的变换为 `B=diag(Rᵀ/L,I)`，写出的矩阵是 `Bᵀ Hsubᵀ R_inv Hsub B`。输出另存升序六特征值、最小特征值的单位特征向量、该向量分别在重力上方向的转动和平移投影，以及纯竖向平移和绕竖向转动的 Rayleigh 商。最弱方向的符号本身没有物理含义；当最小两个特征值接近时，单条特征向量也会变得不稳定。

```sh
python3 tests/test_lio_information.py
python3 tools/summarize_lio_information.py RUN/keyframes --out weighted_geometry.json
```

汇总从逐行存储的 21 个独立矩阵元素重建对称矩阵，独立重新分解特征值，并检查最弱向量、方差闭合、按方向的加权贡献和分组计数。位置或姿态精度仍需轨迹或独立几何证据判断。

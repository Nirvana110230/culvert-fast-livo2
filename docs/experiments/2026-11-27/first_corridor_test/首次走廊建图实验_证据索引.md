## 复核方法

ZIP 内 `SHA256SUMS.txt` 提供逐项 SHA256，ZIP 自身的 SHA256 写在关键指标 `evidence_zip`。解压后可用 Python 运行 `analyze_session.py` 复算会话、SQLite 索引抽取副本及 TUM 统计，`analyze_events.py` 定位两个移动事件；将 Windows 现有地图目录作为 `analyze_map.py` 的参数可复算点云。脚本依赖 NumPy 和 PyYAML。图表使用 `plot_session.py <输出目录>` 与 Matplotlib。板端输入索引提取脚本为 `bag_extract.py`，它用 SQLite 只读模式和增量 BLOB 接口，仅为四个有头的消息读 CDR 开头 12 字节，三路小诊断消息读 JSON。

取证包保留了会话文件、日志摘录、索引和分析脚本。原始 57 个 SQLite 分片仅留板端，既有 PCD 仅留板端和用户指定的 Windows 数据目录。未逐页执行 SQLite 完整性扫描或检查大载荷所有字节，完整回放留待后续需要时开展。[板端证据包](首次走廊建图实验_证据包.zip)

# FAST-LIVO2 B1 首次走廊移动建图实验总结（网页端）

实验日期：2026-11-27（北京时间，UTC+8）  
实验标识：Baseline 01 / `corridor_20261127T075234Z_eiYOUs`  
定位：便携式手推平台真实环境建图基准；待与 Codex 板端取证记录合并。

## 1. 实验目的与结论

本次实验验证 Orange Pi 5 Ultra 上部署的 FAST-LIVO2 B1 能否使用充电宝移动供电、脱离 Windows 电脑，在真实室内环境中同时完成雷达—IMU—相机融合、连续建图、原始数据录制、重力对齐归档和结果导出。实验完成约 12 min 的建图会话和约 180 m 的估计移动路程，成功保存两份点云、完整估计轨迹和七路 ROS Bag。无线维护链路发生过连接超时，恢复后仍是同一次开机及原有建图进程，证明该次移动采集不依赖持续 SSH 连接。

本轮在实际采用的标称 5 V / 3 A 主控供电条件下完成带载工作，具备继续沿用此方案开展短时测试的实证依据。长期供电余量、瞬态电压及最大负载能力尚未测定。几何精度尚待点云局部测量及外部参考验证；本轮不是正式电动轮式或履带底盘的运动控制试验。

## 4. 实验实际操作流程

1. 设备连接、充电宝供电、手机热点无线 SSH；Windows 不参与算法计算和传感器数据传输。
2. 现场检查时间、NVMe、雷达专网 IP/载波/路由、相机 USB 枚举、雷达 Idle 和旧任务状态。
3. 创建独立 FIELD 目录，记录 boot_id，使用板端 tmux 启动 ros2 bag record，SQLite3，512 MiB 分片，100 ms 发现轮询。
4. 同一 ROS 环境下在独立 tmux 会话调用 start.sh --runs-dir "$FIELD"，自动启动雷达、相机、算法与归档。
5. 静止等待重力与轨迹就绪，核对传感器输入、视觉更新、轨迹输出和录包订阅，确认正常后人工推动小车。
6. 电脑留在实验室；无线连接不持续时，板端建图及录包仍独立运行。移动结束后重新无线 SSH，恢复 FIELD/RUN/BAG_JOB 变量并检查同一 boot ID 和会话。
7. 先 stop.sh 完成建图与归档，再对本轮录包 tmux 会话发送 Ctrl+C，等待元数据写入及录包退出。
8. status.sh、result.json、view.sh --run "$RUN" --check、ros2 bag info 共同核对保存结果。
9. VNC/RViz 尝试离线查看后，改用 SCP 仅导出 map 目录至 Windows，原始 Bag 保留在板端；CloudCompare 正确选择 PCD 格式打开。
10. 关闭板端查看器，正常 sync/poweroff，断开全部设备供电。在 Windows 上进行点云和轨迹分析。

### 5.2 工程判断与证据范围

- 现有证据支持 5 V / 3 A 供电方案通过本轮便携式建图带载验证，可继续作为短时实验供电基线。
- 相同 boot ID、相同核心 PID、持续增长的数据、成功归档，说明没有发生导致该会话重启或核心进程更换的供电故障；尚未排除短暂欠压、USB/网口重连、瞬时降频或丢帧。
- 操作手册记载官方推荐 5 V / 5 A 固定 5 V 输入。3 A 档通过实际短测并不改变官方推荐，也不证明 3 A 覆盖所有峰值负载、所有线材及长期高温条件。
- 当前没有实测 USB 端电压、电流、瞬态最低电压或充电宝多口功率分配记录；板端日志只能补充故障证据，不能替代端口电气测量。应先查明板端是否具备可靠的欠压检测能力。
- 对正式底盘长时运行和供电设计，仍需采用最终线束/供电模块开展带载验证。若要证明实际功率余量，后续使用适当的 USB 电压电流测量设备，测主控端并记录同时驱动雷达/同步器时的输出分配。

### 5.3 无线通信

无线 SSH 首次重连报 Connection timed out，第二次成功。同一 boot ID 和四个相同核心 PID，加上录包增长至 28 GiB，支持无持续 SSH 连接仍可独立建图。是否存在采集短时空洞，要进一步检查本轮日志和消息时间戳，不能由重连成功直接推出全程零丢包。

后续建图精度分析：

1. 用几何点云在不同走廊位置选取平坦墙面和地面，计算残差 RMS/P95、平面法向、地面高度与倾角。
2. 以实际卷尺/激光测距数据为参考评价走廊宽度、长度及其他固定尺寸；重复观测墙面厚度作为内部一致性指标。
3. 另行设计有精确物理起终点标记的受控闭合实验，评价累计位置与姿态偏差。
4. 正式电动轮式/履带底盘安装后，分别验证振动、转向及暗光退化、长时间运行与供电余量。

本轮工程放行：B1 便携式移动建图链路已通过本轮真实环境验证；保留该轮数据作为 Baseline 01。没有发现必须立刻修改 B1 的证据。供电方案可继续开展短时测试，最终供电规格与长时可靠性以进一步测量和板端证据为准。
